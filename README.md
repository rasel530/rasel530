### D Star POS — Cloud Point-of-Sale Platform
[rasel530/dstar-cloud-pos](https://github.com/rasel530/dstar-cloud-pos) · Laravel 12 · Alpine.js 3 · Tailwind CSS v4 · PostgreSQL
