## 03 · What I Do

- Deliver web products end to end: schema design, backend logic, interactive UI, and deployment tooling.
- Build financial and reporting logic from *stored facts* — tax, revenue, cost, and due figures that reconcile to the last decimal.
- Design role-based, multi-branch, and multi-tenant systems with audit trails.
- Integrate hardware into web flows: ESC/POS thermal printers, barcode scanners, and label printing.
- Add production hygiene: structured logs, health checks, error tracking, security headers, and rate limiting.
